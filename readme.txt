== Description ==

**Woo WhatsApp Pro** is the most comprehensive WhatsApp marketing and automation solution for your WooCommerce store. It offers order notifications, abandoned cart recovery, smart chatbot responses, and advanced analytics features.

= Core Features (Free) =

* **Multiple API Support** - WhatsApp Business API, Twilio, Ultramsg, WATI, 360dialog
* **All Order Statuses** - Processing, Completed, Cancelled, Refunded, Shipped, etc.
* **Customizable Templates** - Different message templates for each status
* **20+ Placeholders** - Order number, customer name, total, product list, etc.
* **Message Logs** - Record and status of all sent messages
* **Modern Admin Panel** - React-based user-friendly interface
* **Test Mode** - Test before sending real messages
* **Webhook Endpoint** - Receive incoming messages and statuses
* **Setup Wizard** - Easy step-by-step installation
* **API Connection Test** - Check API status with one click

= Pro Features =

* **Flow Builder** - Visual drag-and-drop automation designer
* **Abandoned Cart Recovery** - Recover sales with automatic reminder messages
* **Smart Chatbot** - Keyword-based automatic responses
* **Stock Notification / Waitlist** - Notify customers when products are back in stock
* **Advanced Analytics** - Detailed reports and charts
* **CSV/PDF Export** - Download your reports
* **Multi-language Support** - WPML, Polylang, TranslatePress integration
* **Priority Support** - Fast technical support

= Supported WhatsApp APIs =

1. **WhatsApp Business API (Meta)** - Official API, enterprise use

== Installation ==

= Automatic Installation =

1. From WordPress admin panel, go to Plugins > Add New
2. Search for "Woo WhatsApp Pro"
3. Click "Install Now" and then "Activate"
4. Follow the setup wizard

= Manual Installation =

1. Upload plugin files to `/wp-content/plugins/woo-whatsapp/` directory
2. Activate from the Plugins page
3. Click "WhatsApp" in the left menu
4. Complete the setup wizard

= Minimum Requirements =

* WordPress 5.8+
* PHP 7.4+
* WooCommerce 5.0+
* SSL Certificate (HTTPS)

== Frequently Asked Questions ==

= Which WhatsApp API should I use? =

* **Enterprise use**: WhatsApp Business API (Meta) or 360dialog
* **Quick start**: Ultramsg or WATI
* **Reliable infrastructure**: Twilio

= How do I activate my license? =

1. Purchase the plugin from CodeCanyon
2. Copy your Purchase Code (e.g., a1b2c3d4-e5f6-7890-abcd-ef1234567890)
3. Go to Settings > License section
4. Paste the Purchase Code and click "Activate"

= How does abandoned cart recovery work? =

1. Customer adds products to cart but leaves without purchasing
2. System sends WhatsApp message after specified time (default 1 hour)
3. Message contains cart summary and purchase link
4. Optionally add coupon code to increase conversion rate

= How do I configure the chatbot? =

1. Go to the Chatbot tab
2. Click "Add New Rule"
3. Enter trigger keywords (e.g., price, shipping, return)
4. Write the response message
5. Optional: Add button responses or media

= Why aren't my messages being sent? =

1. Check your API credentials (run connection test in Dashboard)
2. Check phone number format (include country code: +1...)
3. Disable test mode (for real messages)
4. Review error messages on the Logs page
5. Enable debug mode for detailed information

= How do I enable multi-language support? =

1. WPML, Polylang, or TranslatePress must be installed
2. Enable from Settings > Multi-language section
3. Write separate templates for each language in Templates tab
4. System selects the correct template based on customer's language
